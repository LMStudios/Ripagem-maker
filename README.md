# Ripagem Maker

Aplicativo de edição de VSL com transcrição, revisão de falas, takes de produto e exportação para o Premiere.

Este repositório guarda o código e o histórico de mudanças. Para trabalhar em outro computador, clone o repositório e siga o [guia do Electron](electron/README.md). Para instalar o aplicativo, use o pacote do seu sistema conforme o [guia de distribuição](distribuicao/COMO-GERAR-VERSOES.md).

Projetos, vídeos, chaves de serviços e configurações locais ficam no computador. Para retomar a edição de uma VSL em outra máquina, leve também a pasta do projeto e as mídias usadas. Alguns testes precisam de amostras locais em `tests/fixtures`, mantidas fora do repositório.
